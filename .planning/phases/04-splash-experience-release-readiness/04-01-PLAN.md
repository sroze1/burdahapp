SPLASH SCREEN WIDGET (lib/screens/splash_screen.dart):

Create a StatefulWidget named SplashScreen. The Scaffold backgroundColor is Colors.black (matches the reveal screen convention, provides contrast with white text and warm sunset tones — Claude's Discretion resolved).

Layout per D-01: Column with two Expanded children. Top Expanded(flex: 3) holds Image.asset('assets/images/madinah_sunset.png', fit: BoxFit.cover) inside a SizedBox.expand. Bottom Expanded(flex: 2) holds a Padding with three Text widgets per D-02.

Image animation per D-03: mirror the _RevealContent pattern from burdah_reveal_screen.dart. Copy the _saturationMatrix static method. Chain .animate(onComplete: navigationCallback).fadeIn() then .custom(saturation ramp from 1.0 to 1.4) then .custom(hold at saturation 1.4) then .fadeOut(). Scale total chain duration to approximately 6.1 seconds to match the audio length. Distribute timing at the executor's discretion (suggested: ~900ms fadeIn, ~1200ms saturation ramp, ~2800ms hold, ~1200ms fadeOut).

Text section per D-02: first line is Arabic Bismillah string wrapped in Directionality(textDirection: TextDirection.rtl) using GoogleFonts.scheherazadeNew() with white color and bold weight. Second line is romanised transliteration in italic. Third line is English translation with slightly reduced alpha (0.85). Match the text styling pattern from _RevealContent (font sizes, spacing, height values).

Text animation per D-04: chain .animate().fadeIn() then .custom(golden shadow ramp using glowColor const Color(0xFFF5E6C8)) then .custom(sin-wave breathing glow matching the reveal screen's math.sin-based alpha/blur oscillation) then .fadeOut(). Same total duration as image chain.

Navigation per D-06: the image chain's onComplete callback calls context.pushReplacement('/home') guarded by if (!context.mounted) return. The existing _fadePage FadeTransition in app_router.dart provides the crossfade overlap — the Home screen fades in over the still-visible splash content. This satisfies D-06's no-gap requirement.

AUDIO PLAYBACK per D-05:

In initState, create an AudioPlayer instance stored as a field. Call player.setAudioContext(AudioContextConfig(respectSilence: true).build()) to configure iOS silent-switch respect (RESEARCH Pattern 2, SPLSH-04). Then call player.play(AssetSource('audio/bismillah_trimmed.mp3')). Wrap the setAudioContext and play calls in a try-catch block so audio failure never crashes or hangs the app — the visual animation continues regardless. In dispose(), call player.dispose().

ROUTE RESTRUCTURE (lib/router/app_router.dart):

Import splash_screen.dart. Add a new GoRoute with path '/' and pageBuilder returning _fadePage(state, const SplashScreen()). Change the existing HomeScreen GoRoute path from '/' to '/home'. All other routes remain unchanged. initialLocation stays as '/'.

TEST UPDATE (test/widget_test.dart):

Update it to a minimal smoke test that pumps BurdahApp and verifies no exceptions are thrown during initial frame rendering, without asserting on specific text content (since the initial screen is now the animated splash). Remove the obsolete find.text expectations.
